# Demo video (team copy)

- **`OnTrack_demo_final_silent.webm`**: the final demo video (4:51, 1920×1080). Silent, with the exact voice-over lines
  burned in as subtitles and a "Layer N · presenter" tag. Presenters: Vansh (Layer 1), Garv (Layer 2), Kris (Layer 3),
  Anuj (Layer 4).
- **`voiceover_timeline.txt`**: every line with its start time; the same lines are in
  [`docs/pitch/voiceover_script.md`](../docs/pitch/voiceover_script.md) next to the short versions.

Each presenter records their voice over their part, reading the subtitle as it appears. The finished video with voices
is uploaded as unlisted YouTube or Google Drive and linked in the main README. This folder is left out of the code zip
(`.gitattributes`: `media/ export-ignore`).
