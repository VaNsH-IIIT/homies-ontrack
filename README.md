## Repository layout

```
src/ontrack/
  config.py          paths and settings (reads .env)
  l1_factory/        Layer 1: raw -> curated -> golden C360, ID matching, data quality
  l2_ask/            Layer 2: plain-English questions -> SQL or sources, refusals
  l3_features/       Layer 3: feature definitions (structured + text), offline/online
  l4_nba/            Layer 4: policy gate, models, ranking, explanations, overrides
  app/               Streamlit demo (agent card, Ask, governance view)
contracts/           data contract for the golden C360 (YAML, from DC-COLL-001)
benchmark/           benchmark answers CSV (generated by the system, never hand-edited)
docs/                architecture diagram, data quality report, design doc
scripts/             data download and one-command runners
data/                local only, git-ignored (dev samples, DuckDB files)
```

## Setup

1. Python 3.11+ and a virtual environment:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate          # Windows  (source .venv/bin/activate on macOS/Linux)
   pip install -r requirements.txt
   ```
2. Copy `.env.example` to `.env` and set `MAPLE_DATA_DIR` (where the dataset is unzipped) and `ANTHROPIC_API_KEY`.
   The dataset needs ~10 GB free: put it on a drive with space, not inside the repo.
3. Download the data: see [`scripts/download_data.md`](scripts/download_data.md).
